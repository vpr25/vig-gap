Scan the board

Pulls live prices from The Odds API (free key, no card) across every book it covers for a sport, then ranks bets by how far each book's price sits from the no-vig market consensus. This is a consensus proxy, not Pinnacle itself — worth a quick Pinnacle gut-check on your top pick before sizing up.
In %, e.g. 1 = only show 1%+ mispricings

Or paste odds data in manually

If live fetching gets blocked in this environment, open this URL yourself (in a normal browser tab — not a code call, so it isn't subject to the same restriction) and paste the full JSON response below:
https://api.the-odds-api.com/v4/sports/<sport>/odds/?apiKey=YOUR_KEY&regions=us&markets=h2h&oddsFormat=american
Swap <sport> for e.g. basketball_nba, americanfootball_nfl, etc. — same sport keys as the dropdown above.
